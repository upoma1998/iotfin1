# 🌱 IoT-Based Soil Sensing System with Crop Prediction & Fertilizer Recommendation

## 📖 Project Overview
This project was developed as part of my **undergraduate thesis** under the supervision of **Dr. Asaduzzaman**.  
It combines **IoT-based soil sensing**, **real-time data collection**, and **Machine Learning models** to provide actionable insights for farmers in Bangladesh.  

---

## 🔑 Key Features
- **IoT-Based Soil Monitoring**  
  - Real-time dataset constructed using a soil sensing system equipped with **5 sensors**.  
  - Data transmitted via **WiFi** from a transmitter node to a receiver node.  
  - Cloud storage for efficient access and analysis.  

- **Machine Learning for Crop Prediction**  
  - Trained models to predict multiple crops, including:  
    - 🥔 Potato  
    - 🍅 Tomato  
    - 🌾 Three rice classes (representing **61 rice varieties** cultivated in Bangladesh across different seasons).  

- **Fertilizer Recommendation System**  
  - Based on predicted crop type, the system recommends optimal fertilizer levels:  
    - **Urea**  
    - **TSP**  
    - **MoP**  

- **Web Application for Farmers**  
  - Remote soil monitoring.  
  - Real-time, data-driven insights.  
  - Easy-to-use interface for practical field deployment.  

---

## 🛠️ Tech Stack
- **IoT Hardware**: 5 soil sensors + Arduino UNO Microcontroller, NRF24L01 PA+LNA Transmitter and Receiver Node, PLED Display
- **Cloud Platform**: Data storage & analysis  
- **Machine Learning**: Crop prediction & fertilizer recommendation  
- **Web Application**: Farmer dashboard for monitoring  

---

## 🌟 Impact
This system enables farmers to:  
- Monitor soil conditions remotely.  
- Predict suitable crops for their land and season.  
- Receive accurate fertilizer recommendations.  
- Make **data-driven agricultural decisions**, improving yield and sustainability.
